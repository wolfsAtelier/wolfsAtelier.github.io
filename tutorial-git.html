Git desde cero

Aprende el flujo esencial para iniciar un repositorio, guardar cambios con commits y enviarlos a GitHub.

Nivel inicial Terminal Aproximadamente 10 minutos

  • Conectar con GitHub

¿Qué es Git?

Git es un sistema de control de versiones: registra cambios en los archivos de un proyecto para que puedas consultar su historial y trabajar en diferentes líneas de desarrollo.

Un repositorio es el proyecto que Git sigue. Un commit es una captura de cambios guardada en su historial. Antes de crear un commit, eliges qué cambios incluir con git add.

Archivos→ git add→ git commit→ git push

Los primeros pasos guardan cambios en tu computadora. El último, git push, los envía a un repositorio remoto.

1. Configura tu nombre y correo

Git usa esta información como autor de tus commits. Configúrala una sola vez en tu computadora, reemplazando los ejemplos por tus datos: 

git config --global user.name "Tu Nombre"
git config --global user.email "tu-correo@example.com"

Para comprobar la configuración:

git config --global --list

2. Crea un repositorio

En la terminal, entra a la carpeta de tu proyecto. Por ejemplo:

cd ruta/a/mi-proyecto

Inicializa Git en esa carpeta:

git init

Ahora Git comenzará a seguir el proyecto. Puedes revisar el estado de los archivos con: 

git status
Consejo: usa git status con frecuencia. Te indica qué archivos cambiaron y cuáles están preparados para el siguiente commit.

3. Guarda tu primer cambio

Crea o modifica un archivo dentro del proyecto. Después, prepara el archivo para el commit y guarda los cambios en el historial:

Preparar los cambios

git add README.md

Cambia README.md por el nombre del archivo que modificaste. Para preparar todos los cambios del proyecto, puedes usar git add ..

Crear el commit

git commit -m "Añade descripción del proyecto"

Escribe un mensaje corto que describa lo que cambió, por ejemplo: "Añade página de inicio".

Consulta los commits recientes con:

git log --oneline

4. Envía los cambios a GitHub

Crea primero un repositorio vacío en GitHub. GitHub te mostrará la dirección del repositorio; cópiala y úsala en el siguiente comando: 

git remote add origin https://github.com/USUARIO/REPOSITORIO.git

Reemplaza USUARIO y REPOSITORIO por los valores de tu repositorio. Luego, publica la rama local: 

git branch -M main
git push -u origin main
Importante: hacer un commit guarda el cambio en tu repositorio local. git push publica los commits en el remoto. La primera vez, GitHub puede pedirte autenticarte.

En los siguientes cambios, el flujo habitual será preparar, guardar y publicar: 

git add .
git commit -m "Describe el cambio"
git push

git push envía los commits de tu rama local al repositorio remoto configurado.

5. Trabaja con ramas

Una rama te permite trabajar en cambios sin modificar directamente la rama principal. Crea y cambia a una rama nueva con: 

git switch -c nombre-de-mi-rama

Cuando termines, guarda los cambios con git add y git commit. Para volver a la rama principal: 

git switch main

Para listar las ramas locales:

git branch

Comandos para recordar

  • git status: revisa el estado de los archivos.
  • git add archivo: prepara un archivo para el commit.
  • git commit -m "mensaje": registra los cambios preparados.
  • git log --oneline: consulta el historial resumido.
  • git pull: trae cambios del repositorio remoto.
  • git push: publica tus commits en el remoto.

¡Listo para empezar!

Ya conoces el ciclo básico: revisa el estado, prepara los cambios, crea un commit y, cuando uses un remoto, publícalos. Practica primero en un proyecto de prueba para familiarizarte con los comandos.
